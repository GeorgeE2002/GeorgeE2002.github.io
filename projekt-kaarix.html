Webbplats

Kaarix

Kaarix är min första riktiga webbplats. Arbetet har gett mig möjlighet att ta ett större webbprojekt vidare och arbeta med både innehåll, struktur och frontend.

React · TypeScript · TanStack Start · Tailwind CSS

Källkod på GitHub ↗

Projektet

Webbplatsen presenterar Kaarix och produkter för industriella och krävande miljöer. Besökaren kan läsa om verksamheten, se applikationer och hitta kontaktinformation.

Teknik och struktur

Projektets källkod använder React och TypeScript med TanStack Start. Sidornas layout och utseende byggs med Tailwind CSS.

Status

Webbplatsen har ännu inte tagits i bruk på ägarnas domän.
